# Contributing to NebulaSEO

Thank you for your interest in contributing to NebulaSEO! As an open-source autonomous SEO and Growth Engineering agent, community contributions help expand our integrations and tools.

---

## 🛠️ Getting Started

1. **Fork** the repository on GitHub.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/agents.git
   cd agents
   ```

3. **Backend Agent Setup (FastAPI)**:
   ```bash
   cd agent
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

4. **Frontend Dashboard Setup (Next.js 14)**:
   ```bash
   cd dashboard
   npm install
   npm run dev
   ```

---

## 💡 What Can You Work On?

- **New Search & Analytics Connectors:** Ingestors for Ahrefs, Semrush, Bing Webmaster Tools, or DuckDuckGo.
- **Enhanced Autonomous Fixes:** Auto-generating `robots.txt`, `llms.txt`, and OpenGraph dynamic images.
- **CMS Adapters:** WordPress, Ghost, Webflow, and Shopify auto-publishing tools.
- **Agent Models:** Adding Anthropic Claude Tool Calling & OpenAI Structured Outputs alongside Gemini 3 Pro.
